# Routing
การตั้งค่า rout ใน nextjs จะใช้รูปแบบ file system routing ซึ่งหมายถึง การจะเข้าไปที่หน้าเพจต่าง ๆ จะใช้การเข้าถึงโฟล์เดอร์ภายในโปรเจคของเรา โดยจะมีกฏการใช้งานดังนี้

1. ทุก rout ต้องอยู่ภายใน app folder
2. ไฟล์ที่เป็นหน้าแสดงผลจะต้องชื่อ page.js หรือ page.tsx
3. ชื่อโฟลเดอร์จะถูกนำไปใช้ใน path
